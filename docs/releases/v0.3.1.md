## DLP: JSON escapes and encodings of encodings

v0.3.0 normalized the body and decoded base64, hex and URL escapes. A body that quotes those characters as JSON
escapes (`4\u200b242 4242 4242 4242`, `\uff14\uff12…`) still slipped through: the scan saw the escape text, not the
invisible or fullwidth character. v0.3.1 decodes literal `\uXXXX` sequences as another variant, so that form, its
base64, and any mix of the three are normalized and matched like the plain card.

No configuration changes. Image: `ghcr.io/openwaf-dev/egress:0.3.1`.
