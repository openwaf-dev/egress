## DLP: base32

The DLP decoded base64, hex, URL escapes and `\uXXXX` escapes. An agent that encodes the card as base32 (RFC 4648)
went through untouched. Every candidate run is now tried as base32 too when base64 does not yield readable text;
binary results are still discarded, so the guess costs nothing when it is wrong.

Image: `ghcr.io/openwaf-dev/egress:0.3.3`.
